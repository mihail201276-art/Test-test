# Игра «Шарики»

Весёлая мини-игра, в которой цветные шарики двигаются по белому полю, сталкиваются
и **смешивают свои цвета**. Игрок может всасывать шарики мышью в инвентарь
и выпускать их обратно, а также удалять шарики в специальной зоне.

## Как устроена игра

Игровая логика и визуальный интерфейс разделены на два модуля:

- **`logic.py`** — вся игровая логика (без графики):
  - движение шариков и отскок от стенок поля;
  - при касании шарики не отталкиваются, а смешивают цвета по HSV-модели:
    `красный + зелёный = жёлтый`, `синий + красный = пурпурный`;
  - смешивание многих разных цветов делает шарик тусклым (стремится к белому —
    «плохой» результат);
  - «всасывание» шариков в инвентарь мышью;
  - «выплёвывание» шариков из инвентаря обратно на поле;
  - зона удаления: шарик, попавший в неё, исчезает навсегда.
- **`gui.py`** — графический интерфейс на **pygame**:
  - белое игровое поле, шарики с объёмным градиентом и бликом;
  - плавная смена цвета при смешивании и кольцевая вспышка в момент касания;
  - панель инвентаря справа — видно, какие шарики «всасаны»;
  - зона удаления — красная полоса внизу поля.

### Управление (мышь)

| Действие | Результат |
|---|---|
| ЛКМ по шарику | «Всасать» шарик — он прилипает к курсору |
| ЛКМ по пустому полю | «Выплюнуть» последний шарик из инвентаря |
| ЛКМ по зоне удаления | Шарик будет выпущен туда и исчезнет |
| `ESC` или закрытие окна | Выход из игры |

## Запуск локально

Требуется **Python 3.10+**.

```bash
# 1. Установить зависимость
pip install -r requirements.txt

# 2. Запустить игру (два равноценных способа)
python main.py
python gui.py
```

Зависимости: `pygame` (единственная сторонняя библиотека).

## Запуск в Docker с графическим окном

Контейнер открывает настоящее графическое окно, поэтому нужен **X11-сервер**
и проброс дисплея в контейнер.

### Сборка образа

```bash
docker build -t balls-game .
```

### Запуск в Linux

```bash
docker run --rm \
  -e DISPLAY=$DISPLAY \
  -e SDL_AUDIODRIVER=dummy \
  -v /tmp/.X11-unix:/tmp/.X11-unix \
  balls-game
```

Если ничего не открывается — проверьте, что вы вошли в сессию X11
(не по SSH без `-X`), и при необходимости разрешите доступ:
`xhost +local:docker`.

### Запуск в Windows (Docker Desktop)

На Windows потребуется X-сервер, например **VcXsrv**:

1. Установите [VcXsrv](https://sourceforge.net/projects/vcxsrv/) и запустите
   `XLaunch` (оставьте галку **Disable access control**).
2. Запустите контейнер:

```powershell
docker run --rm -e DISPLAY=host.docker.internal:0.0 -e SDL_AUDIODRIVER=dummy balls-game
```

### Запуск в macOS (Docker Desktop + XQuartz)

1. Установите [XQuartz](https://www.xquartz.org/) и перезапустите систему.
2. Разрешите подключения: `xhost +localhost`.
3. Запустите:

```bash
docker run --rm -e DISPLAY=host.docker.internal:0 -e SDL_AUDIODRIVER=dummy balls-game
```

> Обратите внимание: проброс графики в контейнер работает на том же хосте,
> где запущен Docker. Для игры «в облаке» или в CI это не подойдёт.
